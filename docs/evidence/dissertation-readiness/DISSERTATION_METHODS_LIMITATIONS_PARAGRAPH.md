# Dissertation Methods and Limitations Paragraph

This study compares human-authored baseline implementations against AI-generated and deliberately misconfigured variants within a single repository and evaluation protocol. Comparative claims are therefore repository-scoped and protocol-scoped rather than universal claims about AI or human coding in general. Safety, reliability, and robustness are assessed with complementary measures: severity-weighted control risk, control-coverage reliability, false-confidence rate, stability across historical arms, dominance across core metrics, remediation-cost proxy, and adversarial perturbation sensitivity. Confidence intervals are estimated with seeded bootstrap resampling so the reported values are reproducible under the documented reproducibility mode. The green-computing result is framed as a compute-efficiency proxy derived from attack-phase latency and secure success rate, not as direct energy metering. False-confidence findings are threshold-sensitive, so the report includes sensitivity across multiple correctness thresholds. The focal-control table is a sentinel subset chosen for high security impact, and the full-control sensitivity view is included to reduce selection-bias risk. These results support comparison of the observed behaviors in this repository, but they should not be generalized beyond the tested models, prompts, and sample set without replication.
